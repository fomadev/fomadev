KivaDB is a multi-model database written in Rust.

## Highlights

- Key-value, JSON documents and vector search
- Single self-contained binary
- Speaks the Redis protocol

## Recent changes

**v1.7.1** — Read `.kva` files saved by PowerShell correctly. Documentation for MongoDB-style `$number*` imports.

**v1.7.0** — `in` and `like`/`ilike` conditions, unique indexes, KivaDB-named keys. Node.js driver 1.1.0.

**v1.6.0** — In-place JSON changes, atomic field updates, hash indexes, strict query rules, pinned keys, memory bounds, deadline-ordered TTL sweeps, 8-bit quantized HNSW graphs, blocking commands, Redis streams, and the first release of the Node.js driver on npm as `@fomadev/kivadb`.

**v1.5.0** — `set ... if not exists`, `del ... if exists`, Redis pub/sub, approximate vector index (HNSW), encryption at rest (AES-256-GCM), Redis sets and sorted sets, `kivadb backup` / `kivadb restore`, automatic failover, and semantic cache.

**v1.4.0** — TLS on every port, multi-line commands and `.kva` files, and one-command installation on Windows via `install.ps1`.
